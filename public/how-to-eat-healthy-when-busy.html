How it works

Questions people ask

Does a plan make food healthy?
No. FitMunch does not promise a health result. It writes meals to targets you set so the week is decided before you are busy.
What if I only have time for one shop?
The list is built from the whole week, so one shop can cover the meals you committed.
Can I change a day?
Yes. Change the meals or the targets and write a new week. The list follows what you lock.
